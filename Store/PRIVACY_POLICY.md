# naget プライバシー ポリシー

最終更新日: 2026年10月24日

naget (以下「本アプリ」) は、Milkeyyy (以下「開発者」) が提供するデスクトップ用の検索ランチャーです。本ポリシーは、本アプリが扱う情報について説明します。

## 保存する情報

本アプリは、次の情報を利用者の端末内にのみ保存します。

- アプリの設定 (表示言語、テーマ、ショートカットキー、検索エンジンの一覧、アプリ内ブラウザーの設定)
- アプリ内ブラウザーの閲覧履歴
- アプリのログ (Microsoft Store 版以外)

これらの情報は開発者のサーバーへ送信されません。アプリをアンインストールすると、Microsoft Store 版で保存した情報は削除されます。

保存先は Windows では `%AppData%\naget` です。Microsoft Store 版では Windows の仕組みにより、パッケージ専用の領域に保存されます。

## 外部への送信

- 検索を実行すると、入力した検索語が利用者が選択した検索エンジン (Google など) に送信されます。送信先での取り扱いは各検索エンジンのプライバシー ポリシーに従います。
- アプリ内ブラウザーは、OS の WebView (Windows では Microsoft Edge WebView2、macOS では WKWebView) を利用します。これらのコンポーネントは、それぞれの提供元のポリシーに従って情報を扱う場合があります。
- Microsoft Store 版以外の配布版は、更新の確認のために `https://nagetupd.milkeyyy.com/` へアクセスします。この通信には端末の IP アドレスなど一般的な通信情報が含まれます。Microsoft Store 版は更新を Microsoft Store が管理するため、この通信を行いません。

開発者は、本アプリを通じて利用者の個人情報を収集、販売、第三者へ提供しません。

## お問い合わせ

本ポリシーに関するお問い合わせは、Microsoft Store の製品ページに記載の開発元連絡先までお願いします。

# naget Privacy Policy

Last updated: October 24, 2026

naget ("the App") is a desktop search launcher provided by Milkeyyy ("the Developer"). This policy explains how the App handles information.

## Information stored on your device

The App stores the following information only on your device:

- App settings (language, theme, shortcut keys, search engines, in-app browser settings)
- In-app browser history
- App logs (non-Microsoft Store builds only)

This information is not sent to the Developer's servers. Uninstalling the App removes the information stored by the Microsoft Store version.

On Windows, the data is stored in `%AppData%\naget`. For the Microsoft Store version, Windows stores it in the package's private location.

## External communication

- When you search, the text you enter is sent to the search engine you selected (for example, Google). Its handling is governed by that search engine's privacy policy.
- The in-app browser uses the OS web view (Microsoft Edge WebView2 on Windows, WKWebView on macOS). Those components may handle information according to their providers' policies.
- Builds distributed outside the Microsoft Store access `https://nagetupd.milkeyyy.com/` to check for updates. This request includes general network information such as your IP address. The Microsoft Store version does not make this request because Microsoft Store manages updates.

The Developer does not collect, sell, or share your personal information through the App.

## Contact

For questions about this policy, use the developer contact listed on the product page in the Microsoft Store.
